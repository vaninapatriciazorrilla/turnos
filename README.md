# Turnos

App de turnos online para comercios chicos (peluquerías, uñas, estética, consultorios).

- `index.html?n=slug` → página pública donde el cliente reserva.
- `admin.html` → panel del comercio: entra con su email, crea su página y ve o cancela turnos.
- `css/estilos.css` → diseño.
- `js/config.js` → claves de Supabase.
- `js/reservas.js` → lógica de reservas.
- `js/admin.js` → lógica del panel.
